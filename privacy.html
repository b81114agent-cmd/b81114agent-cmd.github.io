Privacy Policy

Last updated: 2026-11-25

rclone-backup is used only by its owner to back up the owner's own files.

  • It requests the Google Drive drive.file scope, so it can only access files it created itself.
  • Files are encrypted on the owner's server before upload. Google cannot read their contents.
  • No data is collected from, shared with, or sold to anyone else. There are no analytics or ads.
  • The OAuth token is stored only on the owner's private server.

Questions: open an issue on GitHub.
